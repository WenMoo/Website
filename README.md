# 必凡娱乐招聘品牌站

第一期招聘品牌宣传站，参考点点互动招聘官网的信息架构与视觉节奏，使用 **Vite + Vue 3 + TypeScript + Vue Router + Tailwind CSS** 实现。

本期包含首页、社招/校招/实习/Elite 落地页、企业文化页和隐私政策，**不含职位搜索、登录和投递**。

## 本地运行

需要 Node.js 18+。

```bash
npm install
npm run dev
```

浏览器打开终端提示的本地地址即可。地址形如 `http://localhost:5173/#/`，点「必凡乐活」会进入 `#/life`。

```bash
npm run build
npm run preview
```
